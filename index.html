    Read the setup guide
    Can I run it for free?

    Yes, for a personal briefing using a public repository and sources within their free limits. Standard GitHub Actions runners are free for public repositories; Open-Meteo's free endpoint is for noncommercial use. A free Twelve Data key does not guarantee PH stock access. No paid AI inference is needed.

    What if a source or delivery fails?

    The email lists missing data and keeps the useful sections. SMTP uses verified TLS, with a port-587 fallback for transient failures before submission. Partial or uncertain deliveries are not automatically retried. Failure artifacts record the delivery stage; check them and Gmail Sent before resending. Optional ntfy and Healthchecks integrations help monitor runs.

    Does this demo change my real email?

    No. Toggles and ordering exist only in this page's memory. No provider calls, credentials, configuration writes, or email sending are connected to the demo. Reload or choose Reset demo to restore the sample.

    How do I preview safely?

    Run python daily_updates.py --dry-run, or select dry_run when starting the GitHub Actions workflow. Preview runs do not send email or ping the delivery monitor. The production email includes explicit sections and a plain-text alternative.

    Can I change what I receive?

    Edit the tracked plugins.yaml file to enable sections and choose their order. Set your city, coordinates, timezone and exact model IDs in its settings or environment overrides. Preview the result locally before enabling delivery; the README includes the commands.

    1. Copy the project to GitHub

      Use your own repository for the script and daily workflow. A public repository keeps standard runner usage free.

    2. Connect your Gmail sender

      Enable two-step verification and create a Google App Password for the sender account. Save the full Gmail address as SENDER_EMAIL and the app password—not your normal password—as SENDER_PASSWORD. Store recipients in repository secrets too.

    3. Choose your plugins and settings

      Edit plugins.yaml to choose sections and their order. Keep Borongan as your default, or choose another location. Add a stock API key only if your plan supports the exchange.

    4. Preview, then enable delivery

      First run the workflow with dry_run selected. Once the preview and credentials are ready, run without it to send. The daily schedule is 2:17 PM Philippine time; actual delivery may vary.
