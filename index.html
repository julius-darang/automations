Read the setup guide
Can I run it for free?

Yes, for a personal briefing using a public repository and sources within their free limits. Standard GitHub Actions runners are free for public repositories; Open-Meteo's free endpoint is for noncommercial use. A free Twelve Data key does not guarantee PH stock access. No paid AI inference is needed.

What if a source or delivery fails?

The email lists missing data and keeps the useful sections. Failed or partially accepted sends save a fallback. Optional ntfy alerts report failed runs; a Healthchecks monitor can catch runs that never start. Check delivery details before resending.

Can I change what I receive?

Edit the tracked plugins.yaml file to enable sections and choose their order. Set your city, coordinates, timezone and exact model IDs in its settings or environment overrides. Preview the result locally before enabling delivery; the README includes the commands.

  1. Copy the project to GitHub

    Use your own repository for the script and daily workflow. A public repository keeps standard runner usage free.

  2. Connect your Gmail sender

    Create a Gmail app password with two-step verification enabled. Save it and your recipient addresses in GitHub repository secrets.

  3. Choose your plugins and settings

    Edit plugins.yaml to choose sections and their order. Keep Borongan as your default, or choose another location. Add a stock API key only if your plan supports the exchange.

  4. Enable the daily workflow

    The brief is scheduled for 2:17 PM Philippine time. You can also run it manually. For missed-run alerts, connect the optional monitor in the guide.
